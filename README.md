# PhishGuard 

### AI-Based Phishing Email Awareness Detector

PhishGuard is a Python-based cybersecurity mini project
that identifies potentially suspicious emails using
Machine Learning and rule-based detection.

## Features
- Naive Bayes text classification
- Phishing keyword detection
- Suspicious URL pattern detection
- Rule-based warning system
- Interactive Tkinter GUI
- Animated email analysis

## Technologies Used
- Python
- Tkinter
- Machine Learning
- Naive Bayes

## How to Run

1. Install Python 3.x.
2. Download the project.
3. Open the terminal in the project folder.
4. Run:

python phishguard_detector.py

## Project Purpose

Developed as an educational cybersecurity project
to improve phishing awareness and demonstrate
basic machine learning concepts.

## Disclaimer

This is an educational prototype and should not
be used as a replacement for professional email
security solutions.
